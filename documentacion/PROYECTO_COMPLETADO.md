## 🐛 Soporte y Debugging

### Problema: Página no carga
**Solución:**
1. Verificar F12 > Console por errores
2. Verificar que script está en HTML
3. Verificar que el `id` del body coincida

### Problema: API falla
**Solución:**
1. Verificar que servidor está corriendo
2. Verificar URL en fetch (http://localhost:3000)
3. Verificar token en localStorage
4. Ver error en consola de Node.js

### Problema: Datos no se guardan
**Solución:**
1. Verificar conexión a BD
2. Verificar que tablas existen
3. Ver error en Node.js console
4. Validar estructura de datos JSON
